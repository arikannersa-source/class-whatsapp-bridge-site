# Class WhatsApp Bridge — public compliance site

Static site intended for the Class WhatsApp Bridge A2P 10DLC registration.

## GitHub Pages setup

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then Save.
4. Wait for GitHub Pages to publish.

`https://arikannersa-source.github.io/class-whatsapp-bridge-site/`

## Consent flow

The page generates a written consent receipt locally in the browser. It does **not** send or store the phone number on a server. The recipient gives or shows the receipt to the service operator, who should retain a record before adding the number to the SMS bridge.

This is a technical template, not legal advice. Review the text for your actual program and applicable requirements before relying on it.
